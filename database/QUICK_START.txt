EXAMPLE SEARCHES:
-----------------
Excel: Filter "Key" column for:
  - "damage" (all damage values)
  - "spawn" (mob spawning)
  - "health" (health values)
  - "xp" (XP settings)

SQL: Run queries like:
  SELECT * FROM config_settings
  WHERE setting_key LIKE '%difficulty%';
